This site is built to be used by as many people as possible, including people who use a screen reader, magnification, keyboard navigation or other assistive technology.

## Standard

The goal is to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA and, wherever possible, level AAA.

## What you can expect

- Text follows the font size, zoom and dark or high-contrast mode set in your browser and system.
- The whole site works with a keyboard alone. The first link on every page goes straight to the content.
- Images, charts and diagrams have a text description. Charts also have their data in a table.
- No third-party content loads unless you ask for it.
- There is no infinite scrolling, no pop-up windows and no automatic animation.

## Known limitations

- Diagrams need JavaScript to show as an image. Without JavaScript, the text description is still there.
- Text inside charts grows with page zoom but not with the browser's font size setting. The same values are in the data table.

## Report a problem

If something does not work for you, open a report on the [repository's issues page](https://github.com/henriquefreitassouza/henriquefreitassouza.github.io/issues) with the page, the problem and, if you wish, the technology you use.
