## Qué recoge este sitio

Nada. Este sitio no usa cookies, no tiene analítica de visitas, no tiene formularios y no guarda ninguna información sobre usted.

## Alojamiento

El sitio está alojado en GitHub Pages. Como cualquier servidor web, GitHub puede registrar datos técnicos de las visitas, como la dirección IP, según la [declaración de privacidad de GitHub](https://docs.github.com/es/site-policy/privacy-policies/github-general-privacy-statement).

## Contenido externo

Algunos artículos pueden incluir videos u otro contenido de terceros. Solo se cargan si usted pulsa el botón de cargar. A partir de ese momento, el servicio externo recibe una solicitud de su navegador y se aplica su propia política de privacidad.
