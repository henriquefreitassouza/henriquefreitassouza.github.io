## O que este site coleta

Nada. Este site não usa cookies, não tem ferramentas de análise de visitas, não tem formulários e não guarda nenhuma informação sobre você.

## Hospedagem

O site é hospedado pelo GitHub Pages. Como qualquer servidor, o GitHub pode registrar dados técnicos das visitas, como o endereço IP, conforme a [declaração de privacidade do GitHub](https://docs.github.com/pt/site-policy/privacy-policies/github-general-privacy-statement).

## Conteúdos externos

Alguns artigos podem incluir vídeos ou outros conteúdos de terceiros. Eles só são carregados se você clicar no botão de carregar. A partir desse clique, o serviço externo recebe uma requisição do seu navegador e passa a valer a política de privacidade dele.
